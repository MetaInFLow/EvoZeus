# EvoZeus v0.5.2

EvoZeus v0.5.2 将默认 Skill、维护者 Skill、Runtime/Session Signal Skill 和插件界面统一为中文优先，降低中文用户使用 EvoZeus 时的理解成本。

## 变更摘要

- 默认用户 Skill 的触发说明、路由、Lesson 捕捉、权限边界和验证标准改为中文。
- 维护者、Runtime 和 Session Signal Skill 的流程说明改为中文，同时保留 CLI 命令、路径、字段名、协议枚举和必要英文专有名词。
- Codex、Claude 插件及 marketplace 元数据改为中文描述。
- 保留 `Use when` Skill 触发契约，以及 Session Signal 既有契约测试所需的规范标记。
