# EvoZeus v0.5.6

EvoZeus v0.5.6 让 Codex 会话启动不再因为 EvoZeus 更新而出现 `hook: SessionStart Failed`。

## 变更摘要

- 原因：Codex 在用户信任插件钩子时，会对整个插件目录做指纹。任何发版都会改动插件文件（至少版本号），钩子随即被视为"已修改"，在用户重新审核前不再运行。v0.5.5 修掉了命令里的版本路径，但目录指纹仍会在每次发版时变化。
- 修复：Codex 插件包不再附带会话启动钩子。Codex 中的会话启动更新检查由用户级 EvoZeus 调度钩子（`~/.codex/hooks.json`）完成，它按命令定义信任，不受插件更新影响；Lesson 提示由每条消息的钩子提供。
- Claude Code 没有钩子审核机制，Claude 插件包继续保留启动钩子，行为不变。
- 升级后 Codex 不再提示审核 EvoZeus 插件钩子。

## 验证范围

- `npm test` 全部通过。
- Codex 实测：修改插件目录中任一文件都会让已信任的插件钩子失效；用户级钩子在脚本更新后仍保持信任。
