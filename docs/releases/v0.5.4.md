# EvoZeus v0.5.4

EvoZeus v0.5.4 让新会话能及时拿到新版本：以前会话启动的更新检查和普通命令一样每小时最多一次，发布后最长要等一小时才生效。

## 变更摘要

- 会话启动时（Codex 与 Claude 的启动钩子）距上次检查超过 5 分钟就会检查更新；普通命令仍按 1 小时检查。
- `EVOZEUS_UPDATE_CHECK_INTERVAL_SECONDS` 仍可覆盖检查间隔。
- 检查失败或超时不影响会话，继续使用当前版本。
- 会话启动的 5 分钟间隔不会写入 `update-policy.json`。
