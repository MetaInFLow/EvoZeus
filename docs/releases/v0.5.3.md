# EvoZeus v0.5.3

EvoZeus v0.5.3 让结尾的"值得记一下"提示更少、更好懂，并把用户确认的经验直接提交到所属 Repo 的 GitHub Issue，不再留本地记录。

## 变更摘要

- 提示门槛提高：只有用户刚纠正过、以后大概率还会遇到、或这次造成明显返工时才提示；拿不准不提，同一会话最多一次。
- 提示改为业务语言并写明去处：`💡 值得记一下：<这次发现了什么，以后会怎么做>。要提到 <repo 短名> 的问题列表吗？`；提交成功显示 `📝 已提交：<Issue 链接>`。
- 用户对写明 Repo 的问句明确同意，即授权在该 Repo 创建一个 GitHub Issue；先核对 Repo、查重，公开 Repo 去掉公司、客户和私有项目信息；提交失败时贴出草稿，不写本地记录。
- CoEvolve 启动检查没有需要用户处理的事时，不再显示 `[EvoZeus <渠道>]` 横幅。
