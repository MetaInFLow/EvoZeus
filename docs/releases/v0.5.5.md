# EvoZeus v0.5.5

EvoZeus v0.5.5 修复 Codex 中 EvoZeus 插件启动钩子每次更新后失效的问题。

## 变更摘要

- 原因：Codex 先把插件钩子命令里的 `${CLAUDE_PLUGIN_ROOT}` 展开成带版本号的插件目录，再记录信任指纹；每次 EvoZeus 更新目录名都会变，钩子被视为"已修改"、需重新审核，审核前不运行（`hook: SessionStart Failed`）。
- 修复：钩子命令不再使用 `${…}` 占位符，改为在 Node 内读取 `CLAUDE_PLUGIN_ROOT`（或 `PLUGIN_ROOT`）环境变量。命令文本跨版本不变，信任一次后之后的更新都保持有效。
- 升级到本版本后，Codex 会把这个钩子再提示审核一次（命令文本变了），之后不再重复。
- Claude Code 同样提供该环境变量，Claude 侧行为不变。
